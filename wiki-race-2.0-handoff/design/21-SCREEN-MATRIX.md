# Wiki Race 2.0 화면·상태 매트릭스

기준 문서: `../01-CONFIRMED-SPEC.md`  
용도: 디자인 시안과 이후 프론트 구현의 공통 화면 계약

## 1. 전역 내비게이션

로그인 사용자:

- 사용자 요약: 닉네임·레벨·대표 칭호

- 메인
- 싱글 탐험
- 온라인 대전
- 오늘의 탐험
- 랭킹
- 업적
- 프로필

게스트:

- 메인
- 싱글 체험
- 도움말
- 로그인/회원가입

게임 진행 중에는 전역 내비게이션을 숨기거나 축소하고, 명시적인 `게임 나가기`만 제공한다.

## 3. 게임 공통 레이아웃

### 3.1 상단 HUD

항상 표시:

- 목표 문서
- 현재 문서
- 경과 또는 남은 시간
- 이동 횟수
- 연결/복구 상태
- 나가기

모드별 추가:

- 싱글: 개인 최고 기록 차이 optional
- 1:1: 상대 현재 문서·이동 횟수·연결·아이템 사용 알림
- 그룹: 내 순위·참가자 상태·3등 후 grace 남은 시간

### 3.2 본문 영역

- Wikipedia 제목·목차·본문·표·정보상자·이미지 설명 유지
- 이동 가능한 링크가 일반 링크와 구분되지만 지나치게 장식되지 않음
- 클릭 불가/검열 링크는 텍스트·아이콘으로 이유 표시
- 먹물은 부분 가림이고 HUD·방어 슬롯을 가리지 않음
- 로딩 중 skeleton이 링크 위치를 오인하게 만들지 않음

### 3.3 빠른 링크

- 최대 20개
- 현재 문서/revision에서 순서 안정
- PC 보조 패널, 모바일 바텀시트
- 링크 미리보기 상태와 결과 수 표시

## 4. 1:1 아이템 HUD

- 5개 슬롯
- 공격·탐색·방어·조커 분류 아이콘과 텍스트
- 사용 가능/공통 쿨타임/소비/지속 효과 상태
- hover·focus·long press 설명
- 남은 지속 시간
- 상대가 사용한 아이템 알림
- 보호·반사 상태
- 로딩·카운트다운·복구·결과 중 disabled 이유

모바일에서는 5개 슬롯을 가로 스크롤로 숨기지 말고, 최소 아이콘 행 + 선택 상세 바텀시트를 사용한다.

## 5. 그룹 참가자 표시

참가자 행 정보:

- 순위 또는 진행 순서
- 프로필 아이콘·닉네임·대표 칭호
- 현재 문서
- 이동 횟수
- 진행/완주/관전/연결 끊김/RETIRE
- 방장 표시

PC는 접을 수 있는 보조 패널, 모바일은 기본 축약 바텀시트를 사용한다. 8명이 모두 있어도 Wikipedia 본문 폭을 과도하게 줄이지 않는다.

## 6. 관전

### 기본 보기

- 선택 참가자의 현재 문서 본문
- 목표·현재·시간·이동·연결 상태
- 이전/다음 참가자 또는 참가자 목록
- preset 이모티콘
- 사용자별 숨기기·전체 끄기

### 보조 경로 비교

- 참가자별 경로 노드
- 공통 문서와 갈라진 지점
- 완주/진행/RETIRE
- 강제 이동·조커·되돌리기 이벤트

텍스트 채팅 입력창과 신고 버튼을 만들지 않는다.

## 7. 결과

읽는 순서:

1. 승리/패배/순위/리타이어
2. 시간·이동 횟수·개인 기록 변화
3. 이번 XP·레벨 변화
4. 새 업적과 보상
5. 전체 경로와 다른 참가자 비교
6. 재대결·다른 모드·로비

그룹은 개인 결과를 먼저 보여주고, 방 전체가 진행 중이면 `관전하기`를 주요 행동으로 둔다.

## 8. 랭킹

### 오늘의 탐험

- 세 코스 전환
- 시작 → 목표
- 내 최고 시간·이동
- 시간 → 이동 → 기록 시각 정렬 안내

### 주간 탐험가

- 이번 주 gameplay XP
- achievement XP 제외 안내
- 월요일 초기화 시점

### 탐험가 레벨

- 누적 XP·레벨
- 최대 레벨 없음

새로운 시즌·리그·보상 상점 UI는 만들지 않는다.

## 9. 프로필·업적·보상

프로필:

- 시스템 제공 프로필 아이콘/일러스트 4~6종 중 1개
- 대표 칭호 1개·대표 배지 최대 3개
- 프로필 프레임 1개·프로필 배경 1개
- 경로 색상·경로 효과·완주 효과·관전 이모티콘
- 레벨과 XP
- 싱글/1:1/그룹 통계
- 최근 결과와 경로
- 보유 보상 분류와 서버 확정 장착 상태
- 기존 단일 이미지의 legacy profile icon fallback
- 아이콘 없음·에셋 로딩 실패 시 시스템 기본 이미지

업적:

- 일반 진행바와 단계
- 히든 달성 전 `??`
- 달성한 히든은 조건·날짜·보상 공개
- 보상 자동 지급 상태

사용자 이미지 업로드, 머리·얼굴·의상·손 조립, 상점·재화·구매 버튼·아바타 프리셋은 만들지 않는다. 모바일은 프로필 카드 다음에 보상 inventory를 접는 구조를 사용한다.

## 10. 상태 보드

모든 관련 화면에서 다음 상태를 디자인한다.

| 상태 | 필요한 표현 |
|---|---|
| initial loading | skeleton·진행 불가 |
| document loading | 이전 본문 오입력 방지·공격 비활성 |
| empty | 다음 행동 안내 |
| profile asset error | 시스템 기본 이미지·장착 상태는 유지 |
| legacy profile | 기존 단일 이미지를 프로필 아이콘 위치에 표시 |
| unowned reward | 장착 동작 비활성·보유 필요 안내 |
| API error | 원인 범주·재시도·안전한 로비 이동 |
| offline | 연결 끊김·유예·복구 시도 |
| recovering | 서버 상태 복원 중·입력 잠금 |
| exit confirm | 모드별 손실 결과 설명 |
| countdown | 아이템/링크 비활성 |
| finished | 결과 확정 대기·중복 입력 방지 |
| spectating | 플레이 입력 비활성·관전 UI |
| grace | 그룹 남은 2분 또는 20분 중 실제 남은 시간 |
| RETIRE/FORFEIT | 원인과 기록·XP 처리 |
| reduced motion | 정적 대체 표현 |

## 11. 접근성 완료 기준

- 본문 기본 16px 이상
- 터치 대상 44×44px 이상
- focus visible
- 모달 focus trap·닫기
- 아이콘에 accessible name
- 색상 외 상태 텍스트/형태
- 키보드로 링크·빠른 링크·아이템·탭 접근
- screen reader가 타이머를 매초 과도하게 읽지 않음
- 이모티콘과 효과에 모션 감소 대응
- 프로필 아이콘 대체 텍스트와 보상 장착 상태의 screen reader 이름

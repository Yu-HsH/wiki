## 1. 제품 핵심

Wiki Race는 한국어 위키백과 문서의 내부 링크만 따라 시작 문서에서 목표 문서까지 도달하는 웹게임이다.

핵심 재미는 다음과 같다.

- 엉뚱한 출발점에서 목표를 향해 연결고리를 발견하는 과정
- 링크를 누르기 전 다음 문서를 추론하는 판단
- 시간과 이동 횟수를 함께 줄이는 기록 도전
- 1:1에서 상대의 현재 진행을 보고 대응하는 경쟁
- 그룹에서 서로 다른 경로가 갈라지고 다시 목표에 모이는 관전성

UI와 기능은 Wikipedia 본문 읽기와 링크 선택을 방해하지 않아야 한다.

## 2. 공통 원칙

- 문서 이동과 승패 판정에는 canonical 문서 ID를 사용한다.
- 리다이렉트와 원래 클릭한 제목은 경로 이벤트에 별도로 보존할 수 있다.
- 새로고침은 명시적 이탈이 아니며 진행 상태를 복구한다.
- 브라우저 뒤로가기 또는 게임 나가기는 확인을 받은 명시적 이탈로 처리한다.
- 결과·통계·XP·업적은 서버가 확정한 값만 저장한다.
- 사용자가 보고 있는 Wikipedia 본문과 실제 이동 가능한 링크의 일치가 최우선이다.
- ~~빠른 링크는 실제 본문 링크와 namespace 0 API 링크의 교집합에서 고정한다.~~
- ~~동일 문서·revision의 빠른 링크는 최대 20개로 안정적으로 유지한다.~~
  → **게임 화면에 빠른 링크 블록을 두지 않는다 — 세 모드 전부, 본문 링크만 이동 수단이다.** 현재 문서의 링크 전체 목록은 1:1 탐색 아이템 `link_index`(§5.3)가 제공한다. (정정 2026-09-30 — §0)
- 표·정보상자·이미지 설명·둘러보기 링크를 임의로 제거하지 않는다.
- 같은 이동 요청의 연속 중복 처리를 막는다.

## 3. 모드 구성

### 3.1 랜덤 탐험

- 시스템이 시작 문서와 목표 문서를 정한다.
- 정상 완주 시 시간·이동 횟수·전체 경로를 저장한다.
- 동일 코스 개인 기록 단축을 추적한다.
- 로그인 사용자는 XP·업적·기록을 얻는다.

### 3.2 목표 지정 탐험

- 사용자가 목표 문서를 검색해 선택한다.
- 시작 문서는 시스템이 정한다.
- 지나치게 쉬운 동일 코스 반복 XP 파밍을 막는다.
- 완주 기록과 경로는 저장하되 같은 시작·목표의 반복 XP는 최초만 지급한다.

### 3.3 오늘의 탐험

- ~~매일 모든 사용자에게 같은 세 개의 코스를 제공한다.~~ → **매일 모든 사용자에게 같은 코스 하나를 제공한다.** (범위 제외 2026-09-28 — §0)
- 난이도 라벨은 붙이지 않는다.
- 사전에 준비한 시작 후보와 목표 후보를 매일 무작위로 연결한다.
- ~~세 코스는 각각 별도 랭킹을 가진다.~~ → **그날 코스 하나의 랭킹을 가진다.** (§0)
- 코스 랭킹 정렬: 완주 시간 → 이동 횟수 → 더 이른 기록 시각.
- 한 코스의 최초 완주에만 기본 XP를 지급한다.
- ~~세 코스 올클리어와~~ 누적 참여일을 업적으로 추적한다. (올클리어는 3코스 전제 — §0)

### 3.4 게스트

- 회원가입 없이 싱글 플레이를 체험할 수 있다.
- 영구 기록·XP·레벨·업적·랭킹·온라인 세부 전적은 저장하지 않는다.
- 로그인 사용자 전용 메뉴와 보상은 명확히 구분한다.
- 게스트 때문에 기존 싱글 플레이 기능을 제거하지 않는다.

## 4. 1:1 대전

### 4.1 기본 규칙

- 두 플레이어가 먼저 목표 문서에 도달하기 위해 경쟁한다.
- **두 플레이어는 같은 시작 문서와 같은 목표 문서를 사용한다.** 목표는 방장이 대기실에서 검색·선택하며, 선택이 저장되면 상대도 바로 본다. (정정 2026-10-01 — §0·§4.3)
- **READY 단계는 없다.** 상대가 방에 있고 방장 목표가 저장되어 있으면 방장만 START할 수 있다. (§4.3)
- **시작 문서는 START 직전에 랜덤으로 가져온 문서다.** 서버는 전달받은 문서 identity의 스냅샷을 검증하고 양쪽에 같은 시작을 배정한다. 목표와 같은 문서는 제외한다. (§4.3)
- 방장은 비아이템전 또는 아이템전을 선택한다.
- 상대 현재 문서와 이동 횟수는 경기 중 공개한다.
- 상대 전체 경로는 경기 종료 후 공개한다.
- 먼저 완주한 사용자가 승리한다.
- 결과와 승패는 서버에서 한 번만 확정한다.

### 4.2 재접속과 기권

- 연결이 끊기면 60초의 재접속 유예를 제공한다.
- 60초 안에 돌아오면 같은 상태에서 계속한다.
- 직접 기권하면 즉시 패배하고 상대는 승리한다.
- 60초 안에 복귀하지 않으면 `FORFEIT` 기권패, 상대 승리로 처리한다.
- 직접 기권·이탈 패배자는 XP를 받지 않는다.
- 상대 기권승은 정상 승리보다 적은 XP를 지급한다.
- 서버 장애로 양쪽이 함께 끊어진 경기는 무효 처리할 수 있어야 한다.

### 4.3 목표 결정과 시작 — 정정 `[사용자 결정, 2026-10-01]`

**확정 흐름:** 방장 목표 검색·선택 → 서버 저장 → 상대 화면에 **"방장이 고른 목표: X"** 표시 → 참가자 2명일 때 방장 START → START 직전 랜덤 시작 문서의 스냅샷 identity로 경기 시작.

- 목표 선택 권한은 방장에게만 있다. 비방장의 `set_duel_target_v2` 호출은 `DUEL_HOST_ONLY`로 거부한다.
- 시작 조건은 **방장 목표 존재 + 참가자 2명**이다. 상대의 목표 제출·준비 완료는 요구하지 않는다.
- 시작과 목표는 canonical `page_id`·`revision_id`로 서버가 검증·정규화하고, 양쪽 `room_players`에 같은 identity를 기록한다.
- 목표는 대기실에서 공개한다. 숨김·동시 공개나 공개용 카운트다운을 새로 만들지 않는다.

## 5. 1:1 아이템전

### 5.1 공통 규칙

- 모든 아이템은 1회용이다.
- 아이템 하나를 사용하면 전체 슬롯에 2.5초 공통 쿨타임을 적용한다.
- 경기당 공격 1·탐색 1·방어 1·조커 1·변칙 1, 총 5개를 지급한다.
- 변칙 슬롯 역할 확률: 공격 50%, 탐색 25%, 방어 25%.
- 변칙 슬롯에는 조커가 나오지 않는다.
- 양쪽은 역할별 개수가 같고 실제 아이템 종류는 달라도 된다.
- 한 플레이어에게 같은 아이템을 중복 지급하지 않는다.
- 새로고침·재접속 후에도 지급·소비·지속 상태를 유지한다.
- 재대결에서는 새 조합을 지급한다.
- 상대의 미사용 아이템은 공개하지 않고, 사용 시 이름과 효과를 알린다.
- 카운트다운·문서 로딩·재접속·결과 확정 중에는 사용할 수 없다.
- 공격 대상이 문서 로딩 중이면 공격을 잠시 비활성화한다.
- 모든 사용·차단·반사·소비·지속 종료를 서버가 확정한다.
- 완주 확정 뒤 도착한 아이템 이벤트는 무효 처리한다.

### 5.2 공격

| 아이템 | 효과 |
|---|---|
| 먹물 공격 | 상대 문서 영역을 4초간 부분적으로 가리고 문서 이동 입력을 막는다. HUD와 아이템은 유지한다. |
| 잘못된 링크 | 상대 현재 문서의 유효한 무작위 링크로 강제 이동한다. 이동 `+1`, 자기 문서·목표 문서는 제외한다. |
| 링크 검열 | ~~6초 동안 상대 유효 링크 약 50%를 봉인한다. 최소 2개는 남기며 본문과 빠른 링크에 동일 적용한다.~~ → **6초 동안 상대 본문 링크 약 50%(최소 2개는 남긴다)를 회색으로 표시하고 클릭을 막는다. 누르면 반응하지 않을 뿐 오류가 아니다. 상대가 `링크만 보기` 색인을 열고 있으면 색인에서도 같은 링크가 회색이다.** (정정 2026-09-30 — §0) |

먹물은 중첩하지 않고 최대 4초까지만 갱신한다. 모션 감소 환경에서는 정적인 가림을 사용한다.

### 5.3 탐색

| 아이템 | 효과 |
|---|---|
| 문서 내 검색 | 15초 동안 검색어 입력, 결과 수, 이전·다음 결과 이동을 제공한다. 문서를 떠나면 종료한다. |
| 링크 미리보기 | 15초 동안 최대 3개 링크의 연결 문서 첫 문장을 이동 전에 확인한다. |
| **링크만 보기** (`link_index`, 추가 2026-09-30 — §0) | **현재 문서의 링크 전부를 가나다순 단어 목록 상자로 연다. 필터 입력창이 있다. 단어를 누르면 그 문서로 이동한다 — 일반 링크 이동과 같은 경로다. 이동하면 닫히고, 최대 20초 유지된다.** 서버 계산을 더하지 않는다 — 목록은 이미 받은 현재 문서의 전체 링크다. |

`링크만 보기`와 `문서 내 검색`은 함께 둔다. 전자는 목표를 모를 때 훑는 도구이고 후자는 근처 문서를 떠올려 적는 도구다 `[사용자 판정, 2026-09-30]`.

### 5.4 방어

| 아이템 | 효과 |
|---|---|
| 편집 보호 | 8초 안에 들어오는 첫 공격 하나를 차단하고 종료한다. 상대에게 보호 상태를 표시한다. |
| 되돌리기 | 직전 문서로 돌아간다. 강제 이동 직후라면 공격 이전 문서와 이동 횟수를 복구하고 지속 방해를 해제한다. |
| 역링크 | 6초 안에 들어오는 첫 공격을 공격자에게 반사한다. 조커는 반사하지 못한다. |

편집 보호로 차단된 공격은 소비된다. 되돌리기는 시작 문서에서 사용할 수 없다.

### 5.5 조커

| 아이템 | 효과 |
|---|---|
| 특수:임의 문서 | 사용자를 이동 가능한 무작위 문서로 보낸다. 목표 직접 도착은 제외하고 이동 `+1`로 기록한다. |
| 문서 맞교환 | 두 플레이어의 현재 문서를 교환한다. 목표는 유지하고 양쪽 이동 `+1`로 기록한다. |
| 역사 되감기 | 두 플레이어를 각각 자신의 직전 문서로 동시에 이동시킨다. 양쪽 이동 `+1`로 기록한다. |

조커는 편집 보호·되돌리기·역링크로 막거나 취소하지 못한다.

### 5.6 제거한 아이템

- 언어 변경
- 링크 하이라이트
- 양쪽 화면 가리기
- 목표·현재 문서 교환
- 기본 아이템으로서의 미니게임 결투

이미 구현된 미니게임은 삭제를 강제하지 않고 이벤트·특수방·향후 로테이션 후보로 보류한다.

그룹 모드에는 아이템을 절대 넣지 않는다. 기존 싱글 아이템 기능은 코드 감사 전 임의 삭제하지 않으며, 공격 대상이 필요한 새 1:1 아이템을 싱글에 억지로 적용하지 않는다.

## 6. 그룹 레이스

### 6.1 기본 규칙

- 참가 인원 3~8명.
- 모든 참가자가 같은 시작 문서와 목표 문서를 사용한다.
- 그룹에는 아이템이 없다.
- 개인 완주 즉시 순위·시간·이동 횟수·경로·결과를 저장한다.
- 완주자는 방을 떠나지 않고 다른 참가자를 관전할 수 있다.

### 6.2 종료 lifecycle

- 전체 제한 시간은 경기 시작 후 20분이다.
- 3등이 완주하면 남은 플레이어에게 2분의 grace period를 시작한다.
- 실제 마감은 `3등 완주 후 2분`과 `시작 후 20분` 중 빠른 시각이다.
- 3등 완주가 방 전체를 즉시 종료하지 않는다.
- 4등 이후도 마감 전 도착하면 정상 완주와 실제 순위를 기록한다.
- 모든 참가자가 완주·리타이어하면 마감 전에도 즉시 종료한다.
- 마감까지 미완주한 참가자는 `RETIRE` 처리한다.
- `DNF`라는 영문보다 사용자 화면에는 `리타이어`를 사용한다.

### 6.3 방장

- 경기 전 방장 이탈 시 남은 참가자 중 입장 순서가 가장 빠른 사람에게 승계한다.
- 경기 중 완주 전 방장이 나가면 해당 참가자는 RETIRE하고 방장을 승계한다.
- 완주 후 관전 중 방장이 나가면 결과는 유지하고 방장만 승계한다.
- 경기 시작 후 방장은 경기 강제 종료·참가자 추방 권한을 갖지 않는다.
- 방장은 경기 운영 권한보다 대기실·재대결 흐름을 위한 소유자 역할이다.

### 6.4 관전과 소통

- 완주 후 기본 화면은 한 참가자의 실제 플레이 화면 관전이다.
- 전체 참가자 경로 비교는 보조 보기로 제공한다.
- 관전 채팅은 제공하지 않는다.
- 정해진 이모티콘만 제공한다.
- 사용자별 이모티콘 숨기기와 전체 끄기를 제공한다.
- 발신자별 3초 쿨타임을 적용하고 같은 사용자의 이모티콘은 하나만 표시한다.
- 계정 전체 차단·신고는 2.0 범위에서 보류한다.

### 7.2 파밍 방지

- 오늘의 탐험은 ~~코스별~~ **그날 코스의** 최초 완주만 기본 XP를 지급한다. (§0)
- 목표 지정 동일 시작·목표 반복은 최초 완주만 기본 XP를 지급한다.
- 같은 상대와 1:1은 하루 3경기까지 100%, 4~5경기 50%, 6경기부터 0% XP다.
- 감쇠 이후에도 정상 승패 기록은 남긴다.
- 업적 XP와 운영 보정 XP는 주간 플레이 랭킹에서 제외한다.

### 7.3 무한 레벨

- 최대 레벨은 없다.
- 레벨은 능력치를 올리지 않는다.
- 다음 레벨 필요 XP:

`min(100 + 25 × floor((현재 레벨 - 1) / 5), 500)`

- 1~5레벨: 레벨당 100 XP.
- 이후 5레벨마다 필요량이 25 XP 증가한다.
- 81레벨부터는 계속 레벨당 500 XP다.
- 레벨 보상의 구체적인 꾸미기 외형은 제작 단계에서 정한다.

## 8. 랭킹과 기록

- 오늘의 탐험: ~~세 코스별~~ **그날 코스의** 시간 → 이동 횟수 → 기록 시각 순위. (§0)

- 탐험가 레벨: 누적 계정 XP와 무한 레벨을 표시한다.
- 업적 XP는 주간 탐험가 점수에 포함하지 않는다.
- 프로필에는 싱글 완주·최고 기록, 1:1 승패·승률, 그룹 순위, 최근 경로를 표시한다.

- 새로운 대규모 시즌제는 2.0 범위에서 추가하지 않는다.

## 9. 업적과 보상

### 9.1 일반 업적

- 조건·진행도·보상을 공개한다.
- 단계형 기본 XP는 30 / 60 / 120이다.
- 초반 안내, 일반 탐험, 오늘의 탐험, 1:1, 그룹, 수집으로 분류한다.
- 초기 활성 계열은 약 18개로 시작하고 카탈로그에서 추가 활성화할 수 있게 한다.
- 후보 계열에는 첫걸음, 첫 도착, 모든 길의 시작, 꾸준한 탐험, 정해진 목적지, 넓어진 세계, 더 나은 길, 오늘도 탐험, 오늘의 올클리어, 이어지는 발걸음, 맞수와의 만남, 승부사, 순수한 승부, 완벽한 대응, 함께하는 탐험, 앞서가는 탐험가, 선두 도착, 끝까지 함께 등이 포함된다.
- 고의 DNF·장시간 방치·연속 패배·채팅 반복·같은 상대 초단기 파밍을 요구하지 않는다.

### 9.2 히든 업적

- 달성 전 이름·조건·진행도·보상·전체 개수를 공개하지 않는다.
- 달성 후 조건과 날짜를 업적 도감에 기록한다.
- 초기 히든 업적은 13개다.
- 재미형 30 XP, 발견형 60 XP, 도전형 120 XP를 기준으로 한다.
- 히든 여부와 실제 난이도는 별도로 판정한다.
- 우연형 보상은 ~~칭호·배지·이모티콘~~ → **칭호·프로필 아이콘·이모티콘**, 어려운 도전형 보상은 고유 경로·테두리·완주 효과 중심이다. (정정 2026-10-03 — §0)

- Wiki Race 2.0에서는 머리·얼굴·의상·손의 4부위 조합형 아바타를 구현하지 않는다.
- 장착 가능한 프로필 카드 요소는 ~~시스템 제공 프로필 아이콘 또는 일러스트 1개, 대표 칭호 1개, 대표 배지 최대 3개, 프로필 프레임 1개, 프로필 배경 1개다.~~ → **프로필 아이콘(그림) 1개 · 대표 칭호(글) 1개 · 프로필 프레임(테두리) 1개 · 프로필 배경(질감) 1개다. 배지는 두지 않는다** — 프로필 아이콘은 시스템 제공 기본 아이콘과 업적으로 얻는 아이콘을 포함한다. (정정 2026-10-03 — §0)
- 경기 표현용 꾸미기는 경로 색상·경로 효과, 완주 효과, 관전 이모티콘으로 한정한다.
- 초기 프로필 이미지는 시스템 제공 4~6종을 전제로 하며 사용자 이미지 업로드는 구현하지 않는다.
- 아바타 프리셋과 복잡한 아바타 편집 기능은 계속 보류한다.
- 상단 내비게이션은 닉네임·레벨·대표 칭호 중심으로 유지한다.
- 쉬운 보상도 기본 완성도는 유지하고, 어려운 업적은 고유성·애니메이션·노출 범위를 높일 수 있다.
- 게임 성능을 올리는 보상은 없다.
- 정확한 아트 수량·외형은 디자인 및 제작 단계에서 정하되 존재하지 않는 4부위 에셋을 임의로 만들지 않는다.
- 보상 카탈로그, 보유 inventory, 장착 상태를 분리하고 안정적인 reward bundle ID로 자동 지급한다.
- 장착 요청은 보유 여부를 서버에서 확인하고 서버가 확정한 장착 상태만 저장·표시한다.
- 기존 단일 이미지 또는 4부위 값이 발견되면 삭제하거나 파괴적으로 변환하지 않고 `legacy avatar/profile icon` fallback으로 호환한다.
- 기존 보상 의미는 머리 장식→~~배지 또는~~ 프로필 아이콘, 얼굴 장식→프로필 프레임, 의상→프로필 배경 또는 특별 프로필 일러스트, 손 아이템→이모티콘~~ 또는 배지~~, 의상 세트→프레임+배경 reward bundle, 4부위 장착→프로필 카드 설정 완료로 대응한다. (정정 2026-10-03 — §0)
- 경기 중 사용하는 아이템 inventory는 프로필 보상 inventory와 별도 시스템으로 유지한다.
- 2.0에는 상점, 게임 재화, 유료 재화를 넣지 않는다.

`준비된 탐험가`의 신규 조건은 ~~프로필 아이콘 선택과 대표 칭호 또는 배지 1개 장착이며~~ → **프로필 아이콘 선택과 대표 칭호 장착이며** (정정 2026-10-03 — §0) 보상은 기본 프로필 프레임이다. 신규 ID 후보는 `onboarding_profile_complete`다. 운영 DB나 사용자 기록에 `onboarding_full_avatar`가 이미 쓰였다면 기존 ID의 조건을 덮어쓰지 않고 legacy/retired로 보존한 뒤 신규 ID를 추가한다. 미배포이고 사용자 기록이 없다는 사실이 확인될 때만 안전하게 이름을 바꿀 수 있다.

## 11. 디자인 원칙

- SaaS형 카드·과도한 글래스·네온 중심 화면을 피한다.
- 각진 프레임, 얇은 구획선, 제한된 청회색 포인트를 사용할 수 있다.
- 세 모드는 로비에서 동등한 위계로 제시한다.
- Wikipedia 본문이 게임 화면의 가장 큰 영역이다.
- HUD는 시간·목표·이동 횟수·순위·연결 상태를 빠르게 읽게 한다.
- 그룹은 최대 8명의 상태를 감당해야 한다.
- 모바일은 문서 중심 + 접을 수 있는 바텀시트 구조를 우선한다.
- 프로필 카드는 PC와 모바일에서 같은 장착 상태를 표시하고, 모바일 보상 inventory는 접을 수 있는 섹션 또는 바텀시트로 제공한다.
- 본문 기본 글자는 최소 16px, 터치 대상은 최소 44px다.
- 상태를 색상만으로 구분하지 않는다.
- 키보드 탐색과 모션 감소 설정을 지원한다.

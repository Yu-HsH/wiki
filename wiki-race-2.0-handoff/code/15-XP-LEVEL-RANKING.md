# 기능 패킷 04 — XP·무한 레벨·랭킹

기준 문서: `../01-CONFIRMED-SPEC.md`  
목표: 서버 확정 결과에서만 XP를 지급하고, 끝없이 오르되 능력치에 영향 없는 레벨과 명확한 랭킹을 제공

## 1. XP 카탈로그

| 이벤트 | XP |
|---|---:|
| 랜덤 탐험 완주 | 20 |
| 목표 지정 탐험 최초 완주 | 15 |
| 오늘의 탐험 코스 최초 완주 | 25 |
| 1:1 정상 승리 | 50 |
| 1:1 정상 패배 | 25 |
| 상대 기권승 | 30 |
| 직접 기권·연결 이탈 패배 | 0 |
| 그룹 1위 | 70 |
| 그룹 2위 | 55 |
| 그룹 3위 | 45 |
| 그룹 4위 이후 정상 완주 | 35 |
| 그룹 RETIRE | 0 |

수치는 코드 상수가 아니라 설정 또는 데이터 카탈로그에서 관리한다.

## 2. 지급 원칙

- [ ] 서버 결과 ID당 한 번만 지급
- [ ] XP ledger에 source type/source ID/amount/created_at 기록
- [ ] 재시도·F5·중복 finish로 중복 지급 금지
- [ ] guest 지급 금지
- [ ] CANCELLED·무효 경기 지급 금지
- [ ] 업적 XP와 gameplay XP 구분
- [ ] 운영 보정 XP도 별도 source로 구분
- [ ] 음수 보정은 관리자 경로에서만 가능

## 3. 파밍 방지

- [ ] 오늘 코스는 코스별 최초 완주만 25 XP
- [ ] 같은 시작·목표의 목표 지정은 최초만 15 XP
- [ ] 동일 상대 1:1 일일 1~3경기 100%
- [ ] 동일 상대 4~5경기 50%
- [ ] 동일 상대 6경기부터 0%
- [ ] 일일 경계는 서비스 기준 시간대를 명확히 사용
- [ ] 감쇠 XP와 원래 XP를 ledger에 함께 기록
- [ ] 승패·기록 자체는 XP 감쇠와 무관하게 저장

## 4. 무한 레벨

다음 레벨 필요 XP:

`min(100 + 25 × floor((현재 레벨 - 1) / 5), 500)`

- [ ] 최대 레벨 없음
- [ ] 1~5레벨 필요량 100
- [ ] 5레벨 구간마다 25 증가
- [ ] 81레벨부터 레벨당 500
- [ ] 여러 레벨을 한 번에 오르는 XP 처리
- [ ] 누적 XP를 원장 합계 또는 신뢰 가능한 집계로 계산
- [ ] 레벨은 능력치·아이템 성능에 영향 없음
- [ ] exact cosmetic milestone은 후속 카탈로그로 분리

## 5. 랭킹

### 5.1 오늘의 탐험

- 세 코스별 독립 랭킹
- 정렬: 완주 시간 → 이동 횟수 → 기록 시각
- 같은 사용자의 코스별 최고 기록만 노출
- RETIRE·중단 기록 제외

### 5.2 주간 탐험가

- 정상 gameplay XP 합계
- 월요일 00:00 기준 주간 구간
- 업적 XP·운영 보정 XP 제외
- 동점 시 더 적은 정상 경기 수 또는 더 이른 도달 등 현재 데이터로 일관된 tie-break를 문서화

### 5.3 탐험가 레벨

- 누적 XP와 현재 레벨 표시
- 시즌 초기화 없음
- 같은 레벨이면 누적 XP 우선

## 6. 프로필·결과 표시

- [ ] 결과 화면에서 이번 경기 XP와 지급 이유 표시
- [ ] 감쇠된 경우 원래 값과 감쇠 사유를 과도하지 않게 안내
- [ ] 레벨업 발생 시 결과 확정 뒤 연출
- [ ] 프로필에 현재 레벨·현재/다음 XP 표시
- [ ] 랭킹은 색상만으로 순위·상태를 구분하지 않음
- [ ] guest는 로그인 시 저장 가능하다는 안내만 표시

## 7. 테스트

- XP 이벤트별 정상 지급
- 중복 result ID 재호출
- 50% 감쇠의 정수 처리
- 자정·주간 경계
- 한 번에 여러 레벨 상승
- 80→81 이후 500 cap
- achievement XP의 주간 랭킹 제외
- guest·cancelled·retire·forfeit 조합
- 직접 ledger/table 위조 차단

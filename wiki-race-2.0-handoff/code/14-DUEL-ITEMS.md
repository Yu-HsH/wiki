## 4. 상호작용 매트릭스

| 대상 효과 | 편집 보호 | 되돌리기 | 역링크 |
|---|---|---|---|
| 먹물 공격 | 차단·공격 소비 | 적용 중 효과 제거 | 공격자에게 반사 |
| 잘못된 링크 | 차단·공격 소비 | 공격 전 문서와 추가 이동 복구 | 공격자에게 반사 |
| 링크 검열 | 차단·공격 소비 | 즉시 해제 | 공격자에게 반사 |
| 특수:임의 문서 | 불가 | 취소 불가 | 불가 |
| 문서 맞교환 | 불가 | 취소 불가 | 불가 |
| 역사 되감기 | 불가 | 취소 불가 | 불가 |

추가 규칙:

- 일반 상황의 되돌리기는 직전 문서로 실제 이동하고 이동 횟수 `+1`.
- 강제 이동 직후 되돌리기는 강제 이동으로 늘어난 이동 횟수를 취소한다.
- 잘못된 링크는 자기 문서·목표 문서·유효하지 않은 링크를 제외한다.
- 유효 링크가 없으면 아이템을 소비하지 않는다.
- 특수:임의 문서는 목표 직접 도착과 링크가 거의 없는 문서를 제외한다.
- 문서 맞교환으로 누군가 즉시 목표에 도착하는 경우 사용할 수 없다.
- 조커 이동은 경로 이벤트에 종류를 표시하고 이동 횟수 `+1`.

## 7. 기존 기능 처리

- 그룹에는 아이템을 넣지 않는다.
- 기존 싱글 아이템 기능은 감사 없이 삭제하지 않는다.
- 새 공격/방어 아이템을 싱글에 억지로 적용하지 않는다.
- 기존 `blind`, `cleanse`, `find`, `highlight`, `teleport`, `minigame` 구현과 새 카탈로그를 매핑한다.
- 언어 변경·링크 하이라이트·양쪽 화면 가리기·목표/현재 교환은 새 기본 카탈로그에서 제외한다.
- 미니게임은 이벤트/특수방 후보로 보존 가능하지만 기본 지급에서 제외한다.

## 8. 완료 기준

- 양쪽 역할 수가 항상 같고 중복 없는 5개가 한 번만 지급된다.
- 모든 아이템의 사용·차단·반사·소비가 서버와 두 클라이언트에서 일치한다.
- F5로 아이템을 복구·재추첨·재사용할 수 없다.
- 로딩·카운트다운·결과 확정 중 사용이 거부된다.
- 아이템 이벤트가 경로·이동 횟수·승패와 정확히 연결된다.
- 비아이템전과 그룹 모드에 회귀가 없다.

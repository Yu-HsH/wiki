## 검토 방법

오프라인 검토 페이지에는 17종, 일반·강화·약화, 관련 성공·실패·대상 장면이 있습니다. 제품 애니메이션 부품에 서버 응답 예시를 주입하는 재생기입니다. 실제 판정과 XP는 제품 경기 영상에서 확인할 수 있습니다.

```sh
node scripts/item-effects-review.mjs
npm test
npm run build
```

`index.html`을 `review.js`, `review.css` 및 자산 디렉터리와 함께 열면 서버 없이 재생할 수 있습니다. 실전 영상의 계정은 격리 환경에서 만든 GoTrue 계정입니다. 목표 탐색과 링크 완주는 실제 Wikipedia 문서를 사용했습니다. 일부 아이템은 재현을 위해 격리 DB에서 지급 종류를 바꿨습니다.

2026-11-26 KST, `9df65ed` 위의 후속 작업 트리에서 확인했습니다.

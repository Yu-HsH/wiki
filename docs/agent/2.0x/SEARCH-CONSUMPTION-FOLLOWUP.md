완료 판정에는 타인/다른 방/만료/중복·동시 요청·변조 성공 주장 거부, 빈 입력/미발견 미소비 보존, 같은 표시 본문에 대한 검색 판정 일치, 성공 1회 서버 확정과 재조회/F5 검증이 필요하다. 별도 범위 승인 전에는 구현을 확장하지 않는다.

# Jungle Alive v1 — 구현과 남은 배너 원본 의존성 (2026-11-04)

## 목표와 접근
기존 Jungle65 승인 원화 및 이미지에 구워진 문구/버튼을 **이동·확대·가림 없이 유지**하면서,
웹에서 가능한 2.5D 착시를 더 강하게 구현한다. Live2D Cubism 리깅/독립 캐릭터 모델은 이번 범위 밖이다.

## 원본 검증 (Github main 직전 리비전 이미지 헤더)
- HOME: `hero-jungle-expedition.webp` 실제 **1535×436**, 약 153 KB, VP8 lossy.
- Landing: `landing-final.webp` 실제 **1672×941**, 약 499 KB, VP8 lossy.
- 양쪽 HOME 장식: WebP **480×1200**.
- HOME 렌더링 상한 1400 CSS px → DPR 2에서는 약 2800px 원본이 권장되므로 **현 화질 이슈 #9는 원본 레이어/고해상도 자산 없이는 해결되지 않는다.**
- 원본 업스케일을 2x 저장해도 글자 디테일이 새로 생기지 않는다. 단순 확대를 화질 해결로 주장하지 않는다.

## GPT·코드만으로 구현한 범위
- 승인 원화 위에 추가된 코너 수관 vector SVG(바람에 흔들림), 햇살 2층, 연무,
  입체 낙엽 8개, 반딧불 7개, 먼 새 실루엣; 랜딩·HOME 각각 다른 밀도.
- 마우스 입력을 RAF로 조절하고 가까운 레이어 ±10px/먼 레이어 ±5px로 제한.
  텍스트/원화/버튼 위치는 그대로 두고 `pointer-events:none` 장식만 움직임.
- 장면이 보이지 않거나 탭을 숨기면 애니메이션 정지. `prefers-reduced-motion`이면 전면 비활성화.
  터치·700px 이하 환경은 무거운 레이어와 입자를 줄임.
- 실제 게임 엔진, 로그인, 랭킹, Supabase, Edge, DB, migration 변경 없음.
- 기존 공지사항 PR #13을 조상으로 사용하지만 별도 브랜치/PR로 분리.

## 완성 전 꼭 필요한 작업
1. 원본 PSD, 디자인 소스 혹은 비슷한 고해상도 원화(최소 HOME 가로 3070px,
   Landing 가로 3344px)를 확보하고 **이미지에 구워진 한글 문구와 버튼**을 별도 레이어/HTML로 분리.
2. 원화 단색 업스케일 대신 레이어별 원본을 새로 생성하거나 재수정해서 DPR 1/2 시각 검증.
3. 실제 Vercel Preview 1440/1920/390, PC/모바일, 클릭 영역과 모션/CPU를 시각 검수.
4. 이상 없을 때만 PR 승인·main 병합. 운영 DB·Edge·프로덕션 자동 배포는 별도 사용자 승인 필요.

# Jungle Alive v2 검수 기록 — 2026-11-04 KST

기준: `6a11dafc91196a5dc3d949064ff55ef1a939f229`에서 분기한 `feat/jungle-alive-interactions-20261104`의 작업 트리. 기준 PR #15 위에 쌓는 변경이며, 제품 동작과 일러스트는 기존 Jungle65를 기준으로 삼았다.

## 장면 계약

- 랜딩과 HOME에서 v1의 합성 SVG 수관을 제거했다. 원화의 나무, 낙엽, 반딧불, 햇살, 안개, 먼 새와 패럴랙스는 유지한다. 가까운 반딧불과 먼 안개가 반대 방향으로 조금 움직인다. HOME 입장 시 원화와 CTA의 위치가 서로 어긋나던 확대/이동 효과를 정지했다.
- 랜딩의 로그인과 회원가입은 그림을 움직이지 않고 테두리 빛을 바꾼다. 랜턴은 원화의 불꽃, 나침반은 왼쪽 아래 탁자의 금속 테두리에 맞춰 빛난다. 물과 폭포에 작은 반짝임을 더했다. 데스크톱 인증과 모바일의 읽기 쉬운 인증 버튼은 기존 폼을 바로 연다.
- HOME은 원화와 클릭 영역을 같은 컨테이너에 두었다. 데스크톱과 모바일에서 파란색 CTA의 중심을 탭하면 `/play`로 이동한다. 모바일의 별도 HTML 버튼도 유지한다. 마커와 깃발 세 구역은 게임 상태를 건드리지 않고 원화의 점선을 따라 빛을 한 번 보낸다. 오늘의 도전·랭킹·메뉴는 기존 동작에 포커스와 눌림 표시를 추가했다.
- 터치 화면의 상시 입자는 낙엽 4개·반딧불 3개로 줄인다. 화면 밖이나 숨김 탭에서 배경 모션을 멈춘다. 모션 감소 설정에서는 배경 모션과 경로 이동을 없애고, 탭이나 키보드 입력에 짧은 밝기 피드백만 준다.

## 이미지 분리와 선명도 판정

저장소에서 확인한 원화는 레이어가 합쳐진 WebP다. 랜턴의 빛은 주변 책과 식물에 묻어 있고, 나침반의 테두리와 그림자는 책상에 붙어 있다. 탐험가와 식물·표지판은 전후 배경이 가려져 있다. HOME의 깃발·마커·CTA는 외곽을 따라 딸 수 있지만 가려진 픽셀을 복원해야 하고, 간판은 가지와 잎에 겹친다. 이동·회전용 투명 스프라이트와 깨끗한 배경을 함께 검증할 수 있는 분리 원본은 확인하지 못했다. 따라서 원화 소품 자체는 움직이지 않는다.

| 원화 | 압축 | 1440px 화면 CSS 크기 | 1920px 화면 CSS 크기 | 1920px / DPR 2에서 가로 기기 픽셀 ÷ 원본 픽셀 |
| --- | --- | --- | --- | --- |
| HOME 1535×436 | VP8 손실, 152,576B | 약 1390×395 | 약 1398×397 | 1.821 |
| 랜딩 1672×941 | VP8 손실, 499,436B | 약 1440×810 | 1672×941 | 2.000 |

브라우저에서 `object-fit: contain` 및 원화에 `transform: none`을 확인했다. HOME은 DPR 1에서는 CSS 너비가 원본보다 작지만 DPR 2에서는 약 2,796 기기 픽셀에 1,535 원본 픽셀을 늘려 그린다. 압축이 손실 방식인 것은 헤더에서 확인했다. 원화 편집 파일과 인코더 설정이 없어 초기 압축 품질 수치나 흐림에 대한 각 원인의 기여도는 확정하지 않았다.

ImageGen 기본 도구로 원본을 참조해 재제작한 후보는 **2171×724 PNG**였다. 동일 HOME 레이아웃에 로컬로만 치환해 DPR 2에서 1440/1920/390px로 비교했다. 1440px에서 배너가 395px에서 464px로 높아지고 버튼·마커·점선 좌표와 채도가 달라졌다. 글자는 선명하지만 승인된 비율과 조형을 유지하지 못해 채택하지 않았다. 후보와 비교 화면은 `.temp/jungle-art-review/`에 보존했다. [Issue #9](https://github.com/Yu-HsH/wiki/issues/9)의 화질 문제는 열어 둔다.

후보 생성에는 원본 HOME을 편집 대상으로 넘기고, 1535:436 비율을 자르거나 패딩하지 않은 3070×872 재제작, 원본 색상과 랜드마크 보존, CTA 범위 `x 43.3–64.4%, y 55.5–78.9%` 고정, 기존 한글과 영문 문구 및 마커 숫자 보존을 지시했다.

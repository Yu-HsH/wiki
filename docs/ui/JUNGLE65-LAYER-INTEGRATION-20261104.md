# Jungle65 소품 레이어 통합 검수

2026-11-04 KST · 통합 기준 `3510629` · [Draft PR #16](https://github.com/Yu-HsH/wiki/pull/16) 위의 후속 브랜치.

POC와 v3 검수 브랜치의 HEAD는 `3510629`이고 그 부모는 `6a11daf`다. 두 브랜치의 POC 소스와 복원 PNG는 미커밋 파일이어서 기존 작업 폴더에 보존했다. 이 브랜치는 PR #16의 HEAD에서 시작한다. `.temp`의 데모 HTML, 투명 미리보기, 원본 생성 후보와 검수 캡처는 검수 산출물이다. 실제 페이지는 아래 제품 경로에서 완성된 타일을 읽는다.

| --- | --- | --- |
| 랜딩 | `lantern-repair.png`, `lantern-body.png`, `lantern-flame.png` | 1672×941 장면. 받침점 `(127,716)`에서 본체를 흔들고, 불꽃은 유리 마스크 안에서 따로 움직인다. 호버는 밝기를 올리고 클릭은 본체의 큰 흔들림과 빛 반응을 함께 재생한다. |

아홉 타일은 검수한 POC의 SVG 마스크와 복원 PNG를 Chromium에서 원본 좌표의 2배 크기로 렌더링한 RGBA PNG다. 2배는 마스크 가장자리의 해상도를 확보하기 위한 렌더 배율이다. 원화 디테일 자체의 해상도는 그대로다. `public/assets/wiki-race/jungle65/layers/`에 저장하고 `junglePropAssets.js`가 장면 좌표와 주기를 제공한다. 랜턴 복원 패치는 확대하면 잎의 크기와 반사광에 차이가 있고, 데스크톱과 모바일의 실제 표시 크기에서는 중복 윤곽이나 큰 이음새가 보이지 않았다.

`JunglePropLayers`는 한 장면의 타일을 모두 디코딩한 뒤 복원 패치와 소품을 같이 표시한다. 누락 시 원래 이미지와 기존 버튼이 표시된다. SVG는 포인터 입력을 받지 않는다. 기존 랜턴 및 경로 마커 버튼에서 소품 반응과 v2 빛 효과를 함께 실행한다. 클릭 변환은 Idle 변환의 안쪽에서 한 번 실행되므로 Idle의 주기는 이어진다. 화면 밖과 숨김 탭은 기존 장면 관찰기로 정지하고, 모션 감소 설정에서는 소품의 위치 변화 없이 기존 빛 반응이 남는다.

나침반 POC에서는 중심 캡을 고정하고 바늘을 회전할 수 있었으나, 바늘 뒤의 남동쪽 눈금과 복원 경계가 확대에서 보였다. 제품은 원본 나침반과 v2 반짝임을 사용한다.

```powershell
npm ci
npm test
npm run build
npx playwright install chromium
node scripts/jungle-alive-browser-smoke.mjs
```

브라우저 스크립트는 Supabase 응답을 로컬 fixture로 처리한다. `.temp/jungle-alive-browser/after/`에 화면 캡처와 `report.json`을 저장한다. 보고서에는 320·390·1440·1920px, DPR 1·2, 모션 감소 켜짐·꺼짐의 실제 화면 좌표와 두 시점의 레이어 변환이 기록된다. `before/`는 `3510629`를 `.temp/jungle-baseline`에 풀어 같은 스크립트의 `--baseline`으로 캡처한 결과다.

## JWT 설정 정정·인증 검증

`LOCAL-RECOVERY-2026-10-29.md` §6의 preview `verify_jwt=true`는 이전 계획이다. 최종 실제 리허설은 전체 로컬 Edge를 `functions serve --no-verify-jwt`로 실행하여 preview도 gateway 검증이 꺼져 있었다. preview handler는 gateway 승인에 의존하지 않고 `Authorization: Bearer`를 추출해 **`admin.auth.getUser(token)`의 실제 회원 확인**을 항상 수행한다. 인증 실패는 예약·위키 조회·정산 전에 401이다. gateway false가 익명 미리보기 허용을 뜻하지 않는다.

# 모바일 시안 정정 기록 — `Wiki Race Mobile Visual Validation v0.1`

> **이 문서는 같은 디렉터리의 시안 HTML 두 개와 함께 읽는다.**
> **시안 파일 자체는 수정하지 않았다** — 시안은 그 시점의 산출물이므로 보존하고,
> 확정값과 어긋나는 지점만 여기에 기록한다 (`AGENTS.md` §4).

| 파일 | 크기 | 역할 |
|---|---:|---|
| `Wiki Race Wireframe Freeze v1 FINAL.html` | **947,543 B** (390행, bundled) | **78화면 요구사항 원본.** 시안이 스스로 SSOT로 지목한 문서 |
| `Wiki Race Mobile Visual Validation v0.1 (Standalone).html` | **4,334,231 B** (394행, bundled) | 10섹션 모바일 변환 검증 보드 (2026-09-01) |

두 파일은 자산을 gzip+base64로 담고 런타임에 푸는 **bundled 형식**이라 원문 검색이 되지 않는다.
이 문서의 인용은 매니페스트를 디코드해 얻은 텍스트에서 가져왔다 `[산출물, 2026-09-02]`.

---

## 0. 왜 이 문서가 필요한가

모바일 보드는 스스로를 이렇게 선언한다:

> "Desktop 확정값(Freeze v1 SSOT · Hybrid D · Desktop Meta …)의 모바일 변환 검증 —
> **새 기능·새 IA·새 스타일 없음.**"

그리고 §11 `SPEC CHECK — 새 기능 0`에서 "새 모드 ✕ · 새 아이템 ✕ · 새 랭킹 ✕ …
**모바일 전용 기능 발명 ✕**"으로 다시 못 박는다.

**그 선언에도 불구하고 확정값과 어긋나는 지점이 있다.** 선언을 그대로 믿고 시안을 읽으면
잘못된 계약이 코드로 들어간다. **이 문서는 그것을 막기 위한 것이다.**

## 1. 판정 완료 — 시안 오류 3건 `[사용자 판정, 2026-09-02]`

### 1.1 Daily 3코스 순차 해제 — **오류. unlock 상태를 만들지 않는다**

| | 내용 |
|---|---|
| **시안 표기** | 모바일 §02 MOBILE HOME — `완료 1 / 3` 아래 세 행: `세종대왕 → 반도체 · 완주 04:12` / `제주도 → 오페라 · **다음 코스**` / `커피 → 남극 · **잠김 해제됨**`. 섹션 부제도 "3코스는 **하나의 진행으로 연결**" |
| **확정 스펙** | `01-CONFIRMED-SPEC.md` §3.3 — **"매일 모든 사용자에게 같은 세 개의 코스를 제공한다."** "세 코스는 각각 별도 랭킹을 가진다." **순차 해제 규정 없음** |
| **Freeze v1도 같다** | 와이어프레임 `07-22 TodayStates`는 **잠금 표기가 없다.** 상태가 `0/3 → 도전` / `1/3 · 남은 코스 2개 → 계속 도전` / `3/3 · 모두 완료`로 **완료 수만 센다** |
| **판정** | **시안 오류.** 3코스는 매일 전부 제공되고 독립 도전 가능하다 |
| **구현 영향** | **unlock state 테이블·컬럼을 추가하지 않는다.** 진행 표시는 완주 기록 조회로 충분하다 |

> **이 판정이 스키마 하나를 없앴다.** 순차 해제였다면 사용자별 코스 해제 상태를 서버가
> 들고 있어야 했고, 게스트 처리(§3.4 "영구 기록 저장 금지")와도 충돌했을 것이다.

### 1.2 XP·레벨 수치 — **목업 샘플. 공식은 그대로다**

| | 내용 |
|---|---|
| **시안 표기** | 모바일 §02 — `탐험가 레벨 Lv.27` · `340/400 XP` · `주간 탐험가 37위 1,240 XP` |
| **확정 스펙** | `01-CONFIRMED-SPEC.md` §7.3 · `15-XP-LEVEL-RANKING.md` §4 — 다음 레벨 필요 XP = **`min(100 + 25 × floor((현재 레벨 − 1) / 5), 500)`** |
| **산술 대조** | Lv.27의 필요 XP는 `floor(26/5)=5` → `100 + 125` = **225**다. **400이 아니다.** (400은 Lv.61~65 구간의 값) |
| **결정적 근거** | **Freeze v1 자신이 같은 `340 / 400 XP`를 `Lv.12`에도 쓴다** (05-03 개인 결과: `Lv.12 340 / 400 XP`, 06 모바일 결과: `Lv.27 340/400`). **한 파일 안에서 같은 값이 두 레벨에 붙어 있으므로 계산값일 수 없다** |
| **시안도 인정한다** | 모바일 §11 FLAGS ③ — **"페르소나 레벨 Lv.27 통일 유지(Desktop Meta에서 이월) — Freeze 원본 대조 1회 필요"** |
| **판정** | **전부 목업 값.** 레벨·XP 공식은 변경되지 않는다 |
| **구현 영향** | **실제 값은 서버 공식 계산값만 사용한다.** 시안 수치를 상수로 옮기지 않는다 |

> **`Lv.27 / 340·400 / 누적 12,480 / 주간 1,240 / 길을 잇는 탐험가`는 하나의 페르소나 샘플이고,
> 두 시안이 그것을 공유한다.** 개별 수치를 따로 해석하지 않는다.

### 1.3 칭호 `길을 잇는 탐험가` — **예시 문구. 신규 칭호가 아니다**

| | 내용 |
|---|---|
| **시안 표기** | 모바일 §02 상단 · Freeze v1 `02-03 Profile`·`02-01 Home` — `Lv.27 · 길을 잇는 탐험가 · 정원` |
| **확정 스펙** | `16-ACHIEVEMENTS-REWARDS.md`의 확정 칭호는 `모든 길의 시작`·`원정대원`·`한 칸이면 충분해`·`한 칸의 차이`뿐이다. **`길을 잇는 탐험가`는 18계열·히든 13개 어디에도 없다** |
| **판정** | **시안용 예시 문구.** 신규 칭호가 아니다 |
| **구현 영향** | **16번 문서의 확정 칭호 목록만 사용하고 신규 칭호를 추가하지 않는다** |

## 2. 판정 대기 — 추가로 발견된 어긋남 3건 `[미판정]`

> **§1의 3건을 판정한 뒤 같은 기준으로 두 시안을 전수 대조하면서 나왔다.**
> **아직 판정되지 않았으므로 정정이 아니라 질문으로 남긴다.** 근거만 적는다.

### 2.1 그룹 2위 XP — **모바일 40 vs Freeze v1 55 vs 확정 스펙 55**

| 출처 | 값 |
|---|---:|
| `15-XP-LEVEL-RANKING.md` §1 (확정) | **55** |
| **Freeze v1** `05-03 PersonalResult` · `06-10 mResult` | **+55 XP** |
| **모바일 §07 RESULT** | **+40 XP** |

**두 시안이 같은 화면에서 다른 값을 요구한다.** Freeze v1은 확정값과 일치하고 모바일만 다르다.
**§1.2와 같은 종류(목업 수치)로 보이지만, §1.2와 달리 이 값은 "그룹 2위"라는 조건에 붙어 있어
규칙값으로 읽힐 수 있다.** 판정이 필요하다.

### 2.2 5번째 아이템 슬롯 명칭 — **모바일 `가변`·`인장` vs 확정 `변칙`**

| 출처 | 표기 |
|---|---|
| `01-CONFIRMED-SPEC.md` §5.1 · `14-DUEL-ITEMS.md` §3 (확정) | **변칙** 슬롯 |
| **Freeze v1** | **`변칙 · 공격 잘못된 링크`** — 확정 용어 그대로 |
| **모바일 §04·§08** | **`가변`**, **`가변 · 공격 인장`**, 슬롯 라벨 **`인장`** |

`인장`은 확정 카탈로그 11종 어디에도 없는 이름이다. **모바일 §11 FLAGS ①이 이 사실을 인정한다** —
"방어·조커·**인장(가변)**은 Freeze 명칭 확정 대기".

> **슬롯 수 5개와 공통 쿨타임 2.5s는 세 문서가 모두 일치한다.** 어긋난 것은 명칭뿐이다.

### 2.3 `오늘의 발견 / TODAY'S DISCOVERY` — **모바일 HOME에만 있다**

모바일 §02 HOME에 `오늘의 발견 / TODAY'S DISCOVERY` 카드가 있고 문서 이미지·제목·요약
(`직지심체요절 …`)을 표시한다. **Freeze v1의 `02-01 Home`에는 이 카드가 없고**,
와이어프레임의 같은 문자열은 전부 레이스 화면의 위키 본문 예시다.

`01-CONFIRMED-SPEC.md` §3.3에도, `17-EXPLORATION-PROFILE-GUEST.md`에도 이 기능은 없다.

**"새 기능 0" 선언과 어긋난다.** 판정 필요: ① 장식/placeholder인가, ② Desktop Meta에서
이월된 것인데 Freeze v1에 누락된 것인가, ③ 신규 기능인가.
③이면 데이터 출처(선정 기준·저장 위치)가 새 계약이 된다.

## 3. 범위 한정 — 이 문서가 보증하는 것과 보증하지 않는 것

**§1의 3건과 §2의 3건을 제외한 나머지 시안 내용은 확정값의 변환으로 신뢰할 수 있다.**
전수 대조에서 확정값과 일치함을 확인한 축은 다음과 같다 `[산출물, 2026-09-02]`:

| 축 | 확정값 | 두 시안 |
|---|---|---|
| 그룹 인원 | 3~8인 | **일치** |
| 그룹 grace / 제한 시간 | 2분 / 20분 | **일치** (stale 문서의 3분/15분이 아니다) |
| 아이템 슬롯·쿨타임 | 5슬롯 · 2.5초 공통 | **일치** |
| 그룹 아이템 | 없음 | **일치** |
| 빠른 링크 | 최대 20 | **일치** |
| 1:1 재접속 유예 | 60초 | **일치** |
| 1:1 XP | 승 50 / 패 25 / 몰수승 30 / 기권 0 | **일치** (모바일 §07 `WIN_NORMAL +50` · `몰수승 +30`) |
| 주간 랭킹 규칙 | 업적 XP 제외 · 월요일 00:00 초기화 | **일치** (Freeze v1 `02-02 Ranking`) |
| 레벨 성질 | 최대 없음 · 능력치 무관 | **일치** |
| 프로필 꾸미기 범위 | 아이콘 1 · 칭호 1 · 배지 최대 3 · 프레임 1 · 배경 1 | **일치** |
| 금지 범위 | 상점·재화·업로드·4부위 아바타·텍스트 채팅 | **일치** (모바일 §11이 명시적으로 부인) |

**보증하지 않는 것:**

- **시각 디자인·레이아웃·모션은 이 문서의 대상이 아니다.** 확정 스펙과 대조할 대상이 아니다.
- **Freeze v1 자신의 내부 불일치는 별도다.** 예: `05-05 OutcomeVariants`의 **싱글 완주 +40 XP**는
  같은 파일 `03-02 SingleSelect`의 `완주 XP 20 / 15 / 최초 완주 XP 25`와 어긋나고
  `15-XP-LEVEL-RANKING.md` §1의 어느 값과도 맞지 않는다. **모바일 시안의 문제가 아니므로
  여기서 정정하지 않고 `docs/agent/PACKET-CONTRACT-GAPS.md`에 공백으로 등재했다.**
- **업적 이름 2건.** Freeze v1의 `앞서가는 탐험가`는 16 §3의 **"추후 활성화"** 목록에 있고
  초기 18계열이 아니다. 모바일 §07의 `다섯 걸음 승부사`는 16 어디에도 없다
  (`승부사`는 있다). 둘 다 §1.3과 같은 예시 문구로 보이나 **판정되지 않았다.**

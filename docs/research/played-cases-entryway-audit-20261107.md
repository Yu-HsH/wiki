
# 실제 플레이 기록과 위키백과 문서 교차검증 (2026-11-07)

**상태:** 연구 전용. 운영 DB SELECT와 공개 위키백과 조회만 수행. 서버/코스 규칙 미변경.

## 자료와 주의
- 랜덤 싱글 운영 기록: completed 12, abandoned 24. abandoned는 브라우저 종료/방치도 포함하며 반드시 난이도로 인한 포기가 아니다.
- 그중 3회 이상 이동한 abandoned 11건을 중심으로 완료 사례와 비교. 8건에서 10회 이상 이동, 5건은 같은 문서를 다시 방문함.
- 목표 15개의 공식 Wikipedia 직접 역링크 수와 동음이의어 pageprops 확인 15/15 성공. 그중 8개는 실제 역링크 출처 문서 제목까지 조회.
- 플레이어 ID/닉네임/방 ID/런 ID/원본 전체 개인별 경로, 정확한 플레이 시각은 저장소에 공개하지 않음.
- 위키백과 페이지는 게임 당시 고정된 문서 개정판과 일부 다를 수 있으며, 저장된 링크 앵커 순서는 화면의 스크롤 위치와 다르다.

## 결과 A: 목표 분야까지 갔으나 마지막 진입로가 없었던 사례

11개 중단 사례 중 6건에서는 플레이어가 목표 문서의 링크에 나오는 관련 상위 개념 문서를 방문했지만, **그 방문 문서에서 목표로 되돌아오는 링크는 최신 게임 캐시에 없었다**. 이 수치는 관측된 증상이며 전체 사용자 원인/실패율이 아니다.

|---|---|---:|---|

| 비도이섬 → 영웅필살 | 대종상·한국 영화 | 5 | 출처는 배우·1990년 대한민국 영화 목록. 한국 영화 일반 문서에는 직행 링크 없음 |

**동음이의어 판정은 Wikipedia pageprops에서 덕곡면, 포니아토프스키 모두 true로 직접 검증함.** 이름을 구성하는 구체적 대상 문서로 이동하는 것은 목표 동음이의어 페이지에 도착하는 것과 다르다.

## 결과 B: 링크 수가 적어도 도착 가능한 정상 사례

| 완료 코스 | 이동 수 | 확인된 접근 설명 |
|---|---:|---|
| 이재범 → 랑시퐁루즈역 | 32 | 목표로 들어오는 공식 링크 4개 중 '제네바'가 있음. 실제 완주 경로도 제네바를 방문. 게임 캐시에서 제네바 → 역 링크 97/125 순번, 위키 문서 '교통' 문단에 역이 설명됨 |
| 댄 브라운 (동음이의) → 김용운 (야구 선수) | 11 | 공식 역링크 36개가 야구 선수·팀·목록에 분포. 실제 유저는 야구/롯데 자이언츠 선수 목록으로 접근했음; 최종 링크는 캐시 기준 19/60 |
| 대한민국 → 훈민정음 | 2회 완료 사례 존재 | 대한민국·조선·한글 등 2회 경로 12개가 기존 캐시 연구에서 관측됨 |

**결론:** 직접 역링크 수가 4라도 이해 가능한 허브/본문에서 진입할 수 있다. 반대로 21개라도 같은 전문 계열 문서끼리만 연결되면 처음 분야를 찾은 사용자가 마지막 관문을 못 통과할 수 있다.

## 결과 C: 오늘의 도전의 '짧지만 부자연스러운' 경로

- 오늘의 도전 김치 → SQL의 완료된 운영 런 4건 중 3건은 첫 클릭이 **김치 → 카카오 (기업)**.
- 운영 게임 최신 김치 스냅샷에서 카카오 표시 링크는 ordinal 320/321 (끝에서 첫 번째). 한국어 위키백과 김치 원문 끝부분에 글 출처·라이선스 안내로 '다음커뮤니케이션(현 카카오)'가 실제 존재.
- 기존 캐시의 2회 이동 최단 경로 두 개는 국제 표준 도서 번호(ISBN), 국제 표준 연속 간행물 번호(ISSN)를 경유. 김치에서 첫 링크는 ordinal 315/321, 318/321으로 출처·서지 영역에 해당.
- 완주 사례 중 김치 → 한국으로 시작하여 여러 문서를 거쳐 소프트웨어로 이동한 경로도 있음.
- 즉 **최단 이동이 짧다고 자연스럽고 발견하기 쉬운 코스는 아니다.** 정상적인 이용자 행동에서도 서지·출처 링크가 실제 탐색 지름길로 활용된다.

## 검증 가능한 우선 작업

1. **동음이의어 목표 예외 처리(높은 확신):** 랜덤 목표 추첨 단계에서 Wikipedia pageprops.disambiguation 신호로 제외할 수 있는지 실험. 기존 Wikipedia random query에 pageprops 요청을 결합하면 추가 API 왕복 없이 확인 가능할 수 있다. 단, 먼저 Edge 계약·성능·재추첨 상한 테스트를 수행하고 사용자 지정 목표는 임의 변경하지 않는다.
2. **마지막 진입 가능성(중요):** 목표 역링크의 단순 개수보다 유입 출처 문서의 주제 분포·중심성·본문 링크 위치를 함께 평가한다. 목표에서 상위 개념으로 향하는 역방향 링크는 그 반대 방향 이동을 보장하지 않는다.
3. **링크 위치 및 역할(중요):** 실제 WikiViewer 렌더링에서 정상 본문·인포박스·표·각주·서지·저작권 문구를 구분해 '짧지만 부자연스러운 경로'를 분류. 링크 허용/차단 정책 변경은 기존 서버 이동 판정에 큰 영향을 줄 수 있으므로 별도 결정.
4. **사람의 판단:** 제한된 코스에 대해 다음 첫 클릭 선택을 기록하고, 막힘 구간을 소수 사용자 실험으로 대조. 지금의 abandoned 상태나 경과시간만으로 코스 불량을 확정하지 않는다.

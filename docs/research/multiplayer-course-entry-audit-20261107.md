# 멀티 모드 실제 플레이 경로·문서 접근성 교차검증 (2026-11-07)

**범위:** 운영 Supabase 데이터베이스 READ ONLY 조회, 위키백과 공개 문서 원문 확인. 플레이·아이템·목표선정 정책·DB·Edge **미수정**.

## 0. 데이터 범위 / 평가의 한계

- `game_rooms`: 1:1 finished 144, waiting 22, 그룹 finished 61 / 진행 또는 유예 3 / waiting 31.
- `match_history`: **1:1 완료 98**, 기권 6, 취소 36 = 140건.
- `group_match_results`: **288건 / 64개 방**, finished 234, retired 54. *참가자별 결과*이므로 게임 단위 표본 288개가 아님.
- `game_move_events`: 그룹 NORMAL_LINK 3,585건, 1:1 NORMAL_LINK 423, REWIND 13, FORCED_LINK 11, RANDOM_TELEPORT 7, UNDO 3. **1:1 이벤트 로깅이 확인되는 방은 정상 링크 기준 28개로, 이전 완료 경기 전체와 같지 않음.**
- 동일 게임에서 함께 플레이한 참가자의 결과는 독립 표본이 아님. 기록 중에는 테스트/재현 세션이 섞여 있을 가능성을 배제할 수 없음.
- 사용자 식별자·닉네임·게스트 토큰·방 코드·런 ID·정확한 세션 시각은 보고서에 기록하지 않음.
- 이번 문서에서 `정방향 클릭 가능`은 **최신 캐시 게임 스냅샷에서 해당 링크가 기록됐는지**를 의미함. 역사적 개정판에서 플레이할 당시의 HTML 구조·사용자 화면 좌표가 같았다는 보장은 없음.

## 1. 그룹: 같은 코스에 여러 사람이 도전했는데도 모두 실패한 사례

64개 결과 기록 방 중 **4개 방에서 finish 0**; 그중 1개는 기록된 인원 1명, 나머지 아래 3개는 4~5명.

| 출발 → 목표 | 결과 | 평균 이동 / 기록된 사용자 | 종료 종류 | 실제 경로의 특징 | 목표 최신 게임 캐시의 진입 연결 |
|---|---|---:|---|---|---:|
| 강감찬 → Shut up | 0/5 완주 | 35.0 | 5 forfeited | 참가자들이 영어·언어·속어·욕설로 이동, 여러 차례 관련 문서 재방문 | 0 |
| 영남대학교 → 곁주머니 | 0/5 완주 | 23.8 | 4 forfeited, 1 time_limit | 해부학·소화계·장기·위창자길 등으로 진입 | 0 |
| 육회 → 섹시 | 0/4 완주 | 52.8 | 4 time_limit | 성적 매력·신체·미디어 등으로 관련 주제 진입 및 재방문 | 0 |

- **Shut up:** 실제 위키백과 문서는 영어 명령어/표현의 의미를 설명한다. 언어·속어로 이동한 참가자가 맥락을 완전히 틀리게 잡았다고 볼 수 없음.
- **곁주머니:** 실제 위키백과 문서는 diverticulum, 즉 식도·위·장기 벽의 주머니 모양 구조를 설명함. 참가자들이 소화계·위·큰창자 등 관련 개념을 찾아 들어왔지만 최신 게임 캐시에서 목표를 직접 가리키는 출발 문서는 발견되지 않았음.
- **섹시:** 실제 위키백과 페이지 자체가 **동음이의어 분류**를 가지는 짧은 설명 페이지. 4명 모두 많은 이동 끝에 time_limit. 목표 자체가 모호함.

**해석 제한:** 캐시 진입 0은 위키백과 전체 링크 0과 동일하지 않음. `forfeited`는 실제 난이도를 입증하지 않고 `time_limit`도 아이템/상황 영향을 받을 수 있음. 그래도 *동일 코스, 여러 참가자가 관련 분야까지 가서도 정방향 진입을 확인하지 못한 기록*은 품질 재평가 우선 후보로 삼을 합리적 근거.

## 2. 그룹: 도착 직전까지 갔는데 경기 종료

그룹 `retired` 54건의 **종료 시점 최종 문서**를 최신 캐시 링크와 대조했음.

| 종료 사유 | 건수 | 마지막 문서에서 목표로 1회 이동 가능 | 해당 목표 링크가 앞 50 순번 |
|---|---:|---:|---:|
| grace_timeout | 22 | **6** | 0 |
| forfeited | 26 | 0 | 0 |
| time_limit | 6 | 0 | 0 |

6개 사례의 실제 목표 링크 위치(0부터 시작하는 순번):

| 코스 | 종료 시점 문서 | 목표 클릭 링크 |
|---|---|---:|
| 셜록 홈즈 → 포메라니안 | 개 품종 | 152 / 158 |
| 셜록 홈즈 → 포메라니안 | 개 | 352 / 433 |
| 협동 → 실미도 | 인천광역시 | 424 / 701 |
| 시우민 → 다우기술 | 한국거래소 | 379 / 472 |
| 커피 → 쿠로바 카이토 | 명탐정 코난의 영화 목록 | 186 / 190 (화면 표시 '괴도 키드') |
| 일본 → 중화민국 | 일본 | 238 / 1,246 |

- `셜록 홈즈 → 포메라니안`은 같은 방 **6명 중 3명 완주, 3명 grace_timeout**. 2명이 `개` 또는 `개 품종`에서 종료됨. 다른 참가자의 완주 이후 유예 종료라는 경쟁 요인을 순수 경로 품질과 섞어서는 안 됨.
- `grace_timeout` 참가자가 마지막 링크를 놓쳤다는 사실만으로 UI의 링크 표시 위치를 확정할 수 없음. `ordinal`은 위키 문서의 링크 저장 순서이지 스크롤 좌표가 아님.

## 3. 1:1: 서로 같은 코스가 아닌 과거 기록 구분

1:1 `match_history` 중 완료 98건:
- **시작과 목표가 둘 다 같은 경기 23건**
- 목표만 같고 시작은 다른 경기 5건
- 시작/목표가 모두 다른 경기 **70건**

따라서 98개를 모두 '같은 코스에서 누가 잘 찾았는가'로 비교하면 오류다. 과거/비대칭 모드·설정이 섞여 있는 기록을 현행 동일 출발/목표 룰과 혼동하지 않는다.

23개 동일 코스의 패자 종료 문서를 직접 조사한 결과 **10건에서 목표까지 유효 링크 1개가 더 존재함**. 단, 여기에 종료 시점 이동 0회도 포함되고, 상대방의 완주와 전투 아이템 때문에 끝날 수 있으므로 *막힌 코스 10개*로 해석해서는 안 됨.

이 중 아이템의 특수 이동 이벤트가 없는 예:

| 같은 출발 → 목표 | 승자의 최종 진입 | 패자의 종료 시점 | 게임 캐시에서 확인된 링크 |
|---|---|---|---|
| 운서동 → 일래스틱서치 | 검색 엔진 목록 → 일래스틱서치 | 검색 엔진 | 검색 엔진에는 직행 링크 없음; 검색 엔진 목록에는 13/170 |
| REACH → 크레이지레이싱 카트라이더 | 카트라이더 → 목표 | 경주 게임에서 슈퍼 마리오 카트로 이동 후 다른 분야 분기 | 카트라이더의 목표 링크 0/6, 경주 게임에는 목표 직행 없음 |
| 함평궤도 → 푸른저축은행 | 상호저축은행 → 목표 | LG그룹에서 종료 | 상호저축은행은 35/88, LG그룹은 직행 없음 |
| 하장 → 수간 | 성교 → 목표 | 동물 학대 | 동물 학대에서도 목표 링크 221/425, 성교는 97/137 |

이 네 코스에서는 **마지막 전문분야로 좁혀가는 선택**이 승부와 연관됐으나, 먼저 완주한 사람이 승리한 경기이므로 패자에게 충분한 시간이 있었는지까지 단정할 수는 없음.

추가 주의: 1:1 일부 경기에는 특수 이동 이벤트가 개입. 기록된 이벤트는 NORMAL_LINK 423 / REWIND 13 / FORCED_LINK 11 / RANDOM_TELEPORT 7 / UNDO 3으로, 순수 링크 탐색 능력과 혼합하지 말 것.

## 4. 목표 이름이 링크에 그대로 나타나지 않는 문제

그룹 **완주 결과 234건의 실제 마지막 클릭**을 확인:
- **72/234건(약 30.8%)**: 클릭 가능한 링크의 텍스트가 정규화하지 않은 목표 문서 제목과 일치하지 않음. 예) 목표 `쿠로바 카이토` → 표시 `괴도 키드`; `전차` → `탱크`; `안데르송 시우바` → `앤더슨 실바`; `김지원 (배우)` → `김지원`. 많은 경우는 쉬운 약칭/표기 차이이므로 곧바로 난이도 페널티로 사용하면 안 됨.
- **87/234건(약 37.2%)**: 승리한 마지막 링크의 저장 ordinal이 **50 이상**.
- 이 통계의 분모는 **같은 방 참가자 결과를 포함**하여 서로 독립적 234개 경로가 아님. 실제 표시 순번/본문 위치와 화면 가시성도 분리해야 함.

## 5. 부수적으로 발견된 공통 링크 주제

서버 캐시에 `카카오 (기업)`으로 들어오는 서로 다른 최신 문서 스냅샷 출처가 **322개**나 확인됨. `김치`, `강감찬`, `협동`처럼 분야가 무관한 곳에서도 첫 이동으로 카카오가 실제 관측됨(그룹 결과 중 첫 이동 4건, 출발 2종). 과거의 `김치 → SQL` 출처 링크 사례와 이어지는 공통 현상이다.

이 수치만으로 허용 링크가 모두 부적절하다고 볼 수 없지만, **서지/저작권/콘텐츠 출처가 여러 분야를 연결하는 게임 공통 허브**로 작동할 수 있는지를 `WikiViewer` 실제 DOM에서 따로 검증할 이유는 충분함.

## 6. 제품 제안: 모드별 차별화

1. **공통:** 링크 개수보다는 *유입 출처의 주제 폭*, *목표 문서 정체성(동음이의어/짧은 용어 설명)*, *표시 문구 별칭*, *실제 클릭 위치*를 여러 신호로 분리해 관측.
2. **자동으로 뽑는 코스:** 동음이의어 목표를 제외할 방법을 우선 실험; 목표를 유입 출처가 상식적인 '입구'로 가리키는지 검증. 사용자 지정 목표는 강제 재선정 금지.
3. **그룹:** 성공 0명인 여러 사람의 경로를 가장 강한 조사 신호로 사용하되, `forfeited`, `time_limit`, `grace_timeout`과 연결해 해석. 충분한 시간 없이 끝났다는 이유로 '품질 미달'로 분류하지 않음.
4. **1:1:** 비교 기준은 **같은 출발/목표 + 일반 이동만 있는 경기**가 우선. 아이템 강제 이동/역이동이 포함된 경기는 별도 그룹으로.
5. **공정성·게임성:** 유예시간이 지나서 마지막 1클릭을 못한 참가자에게 선택적으로 '화면 링크 강조' 같은 힌트를 제공하는 방안은 순위 공정성을 바꾸므로 사용자 판단을 별도로 받아야 하며 이번 조사에서 제안만 기록.
6. **검증 전 자동 재추첨 보류:** 캐시 그래프 미관측을 위키백과 전체 도달 불가능으로 간주하지 않는다. 운영 코드/DB/Edge 미수정.
